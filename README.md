# Smartwerk Landingpage

Statische Website mit Express-Kontakt-API. Lokal `npm ci` und `npm start`
ausführen; SMTP-Konfiguration aus `.env.example` ergänzen. `npm run check`
prüft die JavaScript-Syntax.

Das Marketing-Backend unter `https://smartwerk-software.de/marketing` wird als
eigene Anwendung aus [LightworksShop/marketing-tool](https://github.com/LightworksShop/marketing-tool)
betrieben. Dort erfolgen sämtliche Funktionsänderungen und gemeinsame Releases
für Smartwerk und Lightworks. Die Website enthält keine Kopie des Tools.
Betriebsdetails stehen in [Docs/Marketing-Backend.md](Docs/Marketing-Backend.md).
